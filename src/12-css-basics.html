CSS 규칙의 구조

용어 
h1 {                 /* h1 = 선택자 (selector) */
  color: #1f5f4f;    /* color = 속성(property), #1f5f4f = 값(value) */
  font-size: 28px;   /* 속성: 값;  ← 이 한 줄이 선언(declaration) */
}                    /* { } 안 전체 = 선언 블록 */

문서에 연결하는 세 가지 방법

방법코드쓰임
외부 파일<link rel="stylesheet" href="style.css">기본. 여러 페이지가 공유하고 캐시된다
내부 스타일<style> … </style>그 페이지에만 필요한 소량. 첫 화면 최적화에도 쓰인다
인라인 스타일<p style="color:red">피한다. 재사용 불가, 명시도가 매우 높아 덮어쓰기 어려움

조합 선택자 — 관계로 찾기

기호이름의미
A B (공백)자손A 안 어디든 있는 B
A > B자식A의 바로 아래 B만
A + B인접 형제A 바로 다음에 오는 B 하나
A ~ B일반 형제A 뒤에 오는 모든 형제 B

⬅️ CSS는 왼쪽이 아니라 오른쪽으로 갈 수 없다

"B를 포함한 A"를 고르는 부모 선택자는 오랫동안 없었습니다. 지금은 :has()가 그 역할을 합니다. article:has(img)는 이미지를 포함한 article을 고릅니다. Chrome 105+, Safari 15.4+, Firefox 121+에서 지원되며 현재는 실무에서 쓸 만합니다.

선택자의미

:not(.excluded)해당하지 않는 것
:is(h1, h2, h3)여럿 중 하나. 긴 선택자를 짧게 씁니다
:where(…):is와 같지만 명시도가 0입니다
:disabled / :checked폼 요소의 상태

가상 요소 — 없는 것을 만들기

가상 요소는 콜론 두 개를 씁니다. 실제로 존재하지 않는 부분에 스타일을 넣습니다.

a::before { content: "→ "; }         /* 요소 내용 앞에 삽입 */
a::after  { content: " ↗"; }         /* 뒤에 삽입 */
p::first-line { font-weight: 700; }  /* 첫 줄만 */
::selection { background: #ffe58a; } /* 드래그로 선택한 부분 */

⚠️ content가 없으면 나타나지 않습니다

::before·::after는 content 속성이 반드시 있어야 생성됩니다. 빈 문자열 content: ""이라도 있어야 합니다. 가장 흔한 실수입니다.
또한 ::before로 넣은 글자는 중요한 정보에 쓰면 안 됩니다. 장식용으로만 쓰고, 스크린 리더가 읽는 방식이 일정하지 않습니다.

캐스케이드 — 규칙이 겹칠 때

CSS의 C는 Cascading, 폭포처럼 흘러내린다는 뜻입니다. 같은 요소에 여러 규칙이 적용될 때 어느 것이 이길지를 정하는 절차가 있습니다. 순서대로 비교하고, 앞 단계에서 승부가 나면 끝입니다.

  1. !important가 붙었는가 — 붙은 쪽이 이깁니다.
  2. 명시도(specificity)가 높은가 — 더 구체적인 선택자가 이깁니다.
  3. 나중에 작성된 것 — 위 둘이 같으면 아래에 쓴 것이 이깁니다.

(정확히는 이 앞에 "어느 출처인가"와 "어느 캐스케이드 레이어인가"라는 단계가 더 있습니다. 21장에서 다룹니다.)

명시도 계산하기

명시도는 세 자리 점수로 셉니다. (A, B, C)로 표기하겠습니다.

자리세는 것예
Aid 선택자 개수#header
B클래스, 속성 선택자, 가상 클래스 개수.card, [type=text], :hover
C요소 선택자, 가상 요소 개수div, ::before

비교는 A부터 합니다. A가 크면 B·C가 아무리 작아도 이깁니다.

계산 예시 
p                          → (0, 0, 1)
.title                     → (0, 1, 0)   .title 이 이김
ul li                      → (0, 0, 2)
.menu li                   → (0, 1, 1)   .menu li 가 이김
#nav                       → (1, 0, 0)
.a .b .c .d .e .f .g .h    → (0, 8, 0)   여전히 #nav 가 이김 (A 자리 우선)
style="…" (인라인)          → 어떤 선택자보다도 높음
!important                 → 명시도 비교 이전 단계에서 이김
* , :where(...)            → (0, 0, 0)

🚫 명시도는 10진수 자릿수가 아닙니다

오해 — id는 100점, class는 10점, 요소는 1점이니까 클래스 11개를 쓰면 id를 이긴다. 사실 — 세 자리를 각각 따로 비교합니다. id가 하나라도 있으면 클래스를 100개 써도 절대 못 이깁니다. 널리 퍼진 잘못된 설명이라 주의하세요.

"스타일이 안 먹어요" 해결 순서

🛠️ 현장 노트 — 이 순서대로 확인하세요

  1. 개발자 도구에서 그 요소를 클릭합니다. Styles 패널에 적용된 규칙이 전부 보입니다.
  2. 취소선이 그어진 선언을 찾습니다. 그것이 다른 규칙에 밀린 것입니다. 어느 규칙에 밀렸는지도 바로 위에 보입니다.
  3. 규칙 자체가 목록에 없다면 선택자가 안 걸린 것입니다. 오타, 클래스 이름 불일치, 잘못된 중첩 관계를 확인합니다.
  4. 값이 무효면 브라우저가 그 선언만 버립니다. color: #GGG처럼 잘못된 값이나 단위 누락(width: 100)을 확인합니다.
  5. 그 속성이 그 요소에 적용 가능한지 확인합니다. 인라인 요소에 width는 먹지 않습니다(13장).

💣 !important를 쓰지 마세요

!important는 문제를 해결하는 게 아니라 미룹니다. 다음 사람은 그것을 이기려고 또 !important를 붙이고, 결국 아무도 손댈 수 없는 파일이 됩니다. 정당한 사용처는 수정할 수 없는 외부 라이브러리 스타일을 덮어쓸 때 정도입니다. 그 외에는 선택자를 정리하거나 캐스케이드 레이어(21장)를 쓰는 것이 옳습니다.

상속

일부 속성은 부모에서 자식으로 자동으로 물려받습니다.

상속됨상속 안 됨
color, font-family, font-size, font-weight, line-height, text-align, letter-spacing, visibility, cursor width, height, margin, padding, border, background, display, position, overflow

규칙성이 있습니다. 글자에 관한 것은 대체로 상속되고, 박스(크기·여백·배경)에 관한 것은 상속되지 않습니다. 당연합니다. 부모의 width: 500px를 모든 자식이 물려받으면 화면이 망가지겠죠.

상속을 직접 제어하는 값 
.child {
  color: inherit;   /* 부모 값을 물려받는다 */
  border: initial;  /* 그 속성의 CSS 기본값으로 되돌린다 */
  margin: unset;    /* 상속 속성이면 inherit, 아니면 initial 처럼 동작 */
  padding: revert;  /* 브라우저 기본 스타일로 되돌린다 */
}

🔤 실무에서 자주 쓰는 font: inherit

<button>, <input>, <textarea> 같은 폼 요소는 글꼴을 상속받지 않습니다. 운영체제 기본 글꼴이 적용되어 주변 글자와 따로 놉니다. 그래서 대부분의 프로젝트가 초기 설정에 이 한 줄을 넣습니다.
button, input, select, textarea { font: inherit; }

📌 요약

  • CSS는 선택자 + { 속성: 값; }. 연결은 외부 파일이 기본.
  • 조합 선택자: 공백(자손), >(자식), +(다음 형제), ~(이후 형제).
  • 가상 요소 ::before·::after는 content가 있어야 생긴다.
  • 승부 순서: !important → 명시도 → 작성 순서.
  • 명시도는 (id, 클래스·속성·가상클래스, 요소) 세 자리를 각각 비교한다. 자릿수 합산이 아니다.
  • 글자 관련 속성은 상속되고, 박스 관련 속성은 상속되지 않는다.
  • 폼 요소에는 font: inherit을 따로 넣어야 한다.
