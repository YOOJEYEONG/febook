산술 연산자

➕ +만 특별합니다

한쪽이라도 문자열이면 +는 연결로 동작합니다. 사용자 입력값은 대부분 문자열이므로, 숫자로 다루려면 Number(value)로 명시적으로 변환하세요. "3" + 1 = "31"은 실무에서 실제로 자주 겪는 버그입니다.

논리 연산자와 단축 평가

&&와 ||는 true/false를 반환하지 않습니다. 피연산자 중 하나를 그대로 반환합니다. 이 성질을 이용한 것이 단축 평가입니다.

옵셔널 체이닝 ?.

const user = { profile: null };

// ❌ TypeError: Cannot read properties of null
console.log(user.profile.nickname);

// 옛 방식 — 길고 반복적
console.log(user && user.profile && user.profile.nickname);

// ✅ 옵셔널 체이닝
console.log(user?.profile?.nickname);      // undefined (오류 없음)

// 함수 호출에도
user.getName?.();          // getName이 없으면 그냥 undefined

// 배열 인덱스에도
const list = null;
console.log(list?.[0]);    // undefined

// 기본값과 함께 쓰는 것이 관용구입니다
const name = user?.profile?.nickname ?? "이름 없음";

⚠️ ?.을 남발하지 마세요

?.는 없을 수도 있다는 사실을 알고 있을 때 씁니다. "오류가 나니까 일단 붙이자"는 태도로 모든 곳에 붙이면, 진짜 버그가 조용히 undefined로 지나가 원인을 찾기 어려워집니다. "여기는 왜 없을 수 있는가?"를 먼저 생각하세요.

조건문

// if / else if / else
if (score >= 90) {
  grade = "A";
} else if (score >= 80) {
  grade = "B";
} else {
  grade = "C";
}

// 삼항 연산자 — 값을 고를 때
const message = isLoggedIn ? "로그아웃" : "로그인";

// switch — 하나의 값을 여러 경우와 비교할 때 (=== 로 비교합니다)
switch (status) {
  case "loading":
    showSpinner();
    break;              // ← 없으면 아래로 계속 흘러갑니다
  case "success":
  case "done":          // 여러 case를 묶을 수 있습니다
    showResult();
    break;
  default:
    showError();
}

🔀 무엇을 고를까

  • 값을 고르는 것이면 삼항 연산자. const x = cond ? a : b;
  • 동작을 나누는 것이면 if.
  • 한 값을 여러 상수와 비교하면 switch.
  • 삼항 연산자를 중첩하지 마세요. a ? b : c ? d : e는 읽기 어렵습니다. if로 풀거나 객체 매핑을 쓰세요.
switch 대신 객체 매핑 — 실무에서 자주 쓰는 패턴 
const statusText = {
  loading: "불러오는 중",
  success: "완료",
  error: "실패"
};
const text = statusText[status] ?? "알 수 없음";

반복문

⚠️ 배열에 for...in을 쓰지 마세요

const arr = ["a", "b", "c"];

for (const i in arr) console.log(i, typeof i);
// "0" string, "1" string, "2" string  ← 인덱스가 문자열입니다

// 그리고 배열에 속성을 붙이면 그것까지 순회합니다
arr.extra = "예상 밖";
for (const i in arr) console.log(i);   // 0, 1, 2, extra (!)

for...in은 객체의 키를 도는 문법이고, 상속받은 속성까지 포함합니다. 배열에는 for...of를, 객체에는 Object.entries()를 쓰는 것이 안전합니다.

객체 순회의 현대적 방법 
const user = { name: "홍길동", age: 20 };

Object.keys(user);      // ["name", "age"]
Object.values(user);    // ["홍길동", 20]
Object.entries(user);   // [["name", "홍길동"], ["age", 20]]

for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}

어떤 반복문을 쓸까

상황선택
배열의 값만 필요for...of
새 배열을 만든다map() (29장)
조건에 맞는 것만 고른다filter() (29장)
중간에 멈춰야 한다for...of + break — forEach는 멈출 수 없습니다
객체의 키·값Object.entries() + for...of
비동기 작업을 순서대로for...of + await (36장)
횟수를 미리 모른다while

♾️ 무한 루프 주의

while에서 종료 조건을 바꾸는 코드를 빠뜨리면 브라우저 탭이 멈춥니다. 이 책의 실행기는 격리된 공간에서 돌기 때문에 페이지 전체가 죽지는 않지만, 그래도 결과 창이 응답하지 않게 됩니다. 실행 버튼을 다시 눌러 초기화하세요.

🛠️ 현장 노트 — 중첩과 깊이를 줄이세요

// ❌ 깊은 중첩 — 읽기 어렵습니다
function process(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        doSomething();
      }
    }
  }
}

// ✅ 이른 반환(early return) — 조건이 평평해집니다
function process(user) {
  if (!user) return;
  if (!user.isActive) return;
  if (!user.hasPermission) return;
  doSomething();
}

📌 요약

  • +는 한쪽이 문자열이면 연결이 된다. 입력값은 Number()로 변환.
  • &&·||는 불리언이 아니라 피연산자 중 하나를 반환한다.
  • ?.은 없을 수 있음을 알 때만 쓴다. 남발하면 버그가 숨는다.
  • 값 선택은 삼항, 동작 분기는 if. 삼항 중첩 금지.
  • switch의 break를 빠뜨리면 아래로 흘러간다.
  • 배열은 for...of, 객체는 Object.entries(). 배열에 for...in은 금지.
  • 이른 반환으로 중첩을 줄인다.
