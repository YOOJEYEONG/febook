# 프엔북 — 비전공자를 위한 프론트엔드 완전 학습서

비전공자가 0부터 시작해 실무 프론트엔드 개발자가 되기까지의 과정을 담은 웹 e-book입니다.
**12부 84챕터**, 브라우저에서 바로 코드를 실행하며 배웁니다.

## 특징

- **빌드 도구 없음** — `index.html`을 더블클릭하면 바로 열립니다
- **인앱 코드 실행기** — 본문 예제를 그 자리에서 수정하고 실행
- **진도 저장 · 전체 검색 · 챕터별 퀴즈 · 용어 사전(290개)**
- PC·모바일 어디서나, 라이트/다크 모드 지원

## 구조

```
├── index.html            표지 · 전체 목차 · 진도 대시보드
├── glossary.html         용어 사전
├── search.html           검색 결과
├── ch/                   챕터 84개 (자동 생성 — 직접 수정하지 마세요)
├── src/                  ⭐ 챕터 본문 원본. 내용을 고칠 때는 여기를 고칩니다
├── assets/
│   ├── css/book.css      단일 스타일시트
│   ├── js/               app · runner · quiz · glossary
│   └── data/             toc · glossary-data · search-index(자동 생성)
└── tools/                빌드 스크립트
```

## 내용을 고치려면

```bash
# 1. src/ 안의 해당 챕터 파일을 수정
# 2. 전체 빌드 (챕터 생성 → 용어 자동 표시 → 검색 색인 생성)
node tools/build.js

# 3. 검사 (전부 통과해야 배포)
node tools/check-links.js      # 내부 링크·앵커
node tools/check-content.js    # 퀴즈 데이터 · 챕터 상호 참조
node tools/check-external.js   # 참고 자료의 외부 링크 생존 여부
```

> `check-external.js`는 네트워크를 씁니다. `w3.org`는 봇 요청에 403을 주므로
> 실패로 잡혀도 실제로는 정상인 경우가 많습니다. 브라우저로 한 번 확인하세요.

목차·챕터 순서를 바꾸려면 `assets/data/toc.js`를,
용어를 추가하려면 `assets/data/glossary-data.js`를 수정한 뒤 다시 빌드합니다.

## 로컬에서 보기

```bash
# 그냥 열기 — 대부분의 기능이 동작합니다
open index.html

# 또는 로컬 서버 (권장)
npx serve
python3 -m http.server 8000
```

## 배포

정적 파일뿐이므로 어떤 정적 호스팅에도 올릴 수 있습니다.

`main`에 푸시하면 Vercel이 자동으로 프로덕션 배포합니다.
수동 배포가 필요하면:

```bash
npx vercel deploy --prod
```

## 집필 원칙

1. **정확성 최우선** — 모든 설명은 MDN, WHATWG·W3C 명세, 각 도구의 공식 문서를 근거로 합니다.
   챕터마다 실제 출처 링크를 남겼습니다.
2. **버전 명시** — 버전에 따라 달라지는 내용은 기준 버전을 표기하고, 브라우저 지원 범위를 함께 적습니다.
3. **사실과 취향의 분리** — 실무 관행은 `현장 노트` 상자로 따로 표시합니다.
4. **오해 교정** — 널리 퍼진 잘못된 통념을 `자주 하는 오해` 상자에서 명시적으로 바로잡습니다.
