배열 기본

const fruits = ["사과", "바나나", "포도"];

fruits[0];              // "사과"  — 0부터 시작
fruits.length;          // 3
fruits[fruits.length - 1];  // 마지막
fruits.at(-1);          // "포도"  — 음수 인덱스 지원 (더 편합니다)

fruits[10] = "키위";    // 중간이 비어 버립니다 — 이렇게 쓰지 마세요
console.log(fruits.length);  // 11

🕳️ 배열은 "고정된 상자 줄"이 아닙니다

JavaScript의 배열은 사실 객체이고, 인덱스는 숫자처럼 보이는 키입니다. 그래서 아무 인덱스에나 값을 넣을 수 있고 중간이 비어(희소 배열) 버릴 수도 있습니다. 길이는 늘어나지만 그 자리들은 비어 있는 상태라 map·forEach가 건너뜁니다. 혼란의 원인이므로 항상 push나 전개 구문으로 값을 추가하세요.

🆕 원본을 지키는 새 메서드들

sort()·reverse()·splice()가 원본을 바꾸는 것이 오랜 불편이었습니다. 그래서 같은 일을 하되 새 배열을 반환하는 메서드가 추가되었습니다.

arr.toSorted(fn)      // sort 의 안전한 버전
arr.toReversed()      // reverse 의 안전한 버전
arr.toSpliced(1, 2)   // splice 의 안전한 버전
arr.with(0, "새 값")   // 특정 인덱스만 바꾼 새 배열

Chrome 110+, Safari 16.4+, Firefox 115+, Node 20+에서 지원됩니다. 지원 범위가 걱정되면 [...arr].sort()로 복사 후 정렬하면 같은 효과입니다.

고차 함수 — 배열의 핵심

forEach와 map, 무엇이 다른가

// forEach: 반환값이 없습니다(undefined). 각 항목으로 "무언가 하기"
const result1 = [1, 2, 3].forEach(n => n * 2);
console.log(result1);   // undefined

// map: 새 배열을 반환합니다. "변환하기"
const result2 = [1, 2, 3].map(n => n * 2);
console.log(result2);   // [2, 4, 6]
  • 새 배열이 필요하면 map, 부수 효과(출력·DOM 조작)만 필요하면 forEach.
  • forEach는 break로 중단할 수 없습니다. 중간에 멈춰야 하면 for...of를 쓰세요.
  • forEach는 async/await와 함께 쓰면 기대대로 동작하지 않습니다(36장).

reduce 실전

🎯 reduce를 언제 쓸까

배열을 "다른 모양"으로 바꿀 때입니다. 배열 → 숫자, 배열 → 객체, 배열 → 다른 구조.
단순히 변환하거나 걸러내는 것이라면 map·filter가 읽기 훨씬 좋습니다. "reduce로도 할 수 있다"는 이유로 억지로 쓰지 마세요. 동료가 읽고 5초 안에 이해할 수 없다면 for...of가 나은 선택입니다.

sort의 함정

체이닝

새 배열을 반환하는 메서드는 계속 이어 붙일 수 있습니다. 데이터 가공의 흐름이 그대로 코드에 드러납니다.

const result = orders
  .filter(o => o.price >= 3000)              // 3000원 이상만
  .map(o => ({ ...o, price: o.price * 0.9 })) // 10% 할인
  .toSorted((a, b) => b.price - a.price)      // 비싼 순
  .slice(0, 3)                                // 상위 3개
  .map(o => o.item);                          // 이름만

🔁 체이닝은 매번 배열을 새로 만듭니다

위 코드는 배열을 다섯 번 순회합니다. 항목이 수백~수천 개라면 전혀 문제없습니다. 가독성이 압도적으로 중요합니다.
수십만 개를 다룬다면 그때 for...of 한 번으로 합치는 것을 고려하세요. 측정하기 전에 최적화하지 마세요.

배열 만들기와 변형

Array.from({ length: 5 }, (_, i) => i);      // [0,1,2,3,4]
Array.from("abc");                            // ["a","b","c"]
Array.from(document.querySelectorAll("li"));  // NodeList → 진짜 배열
Array.of(7);                                  // [7]  (new Array(7)은 길이 7인 빈 배열)

[1, [2, [3, [4]]]].flat();                    // [1, 2, [3, [4]]]  기본 1단계
[1, [2, [3, [4]]]].flat(Infinity);            // [1, 2, 3, 4]
["a b", "c d"].flatMap(s => s.split(" "));    // ["a","b","c","d"]

[1, 2, 3].join("-");                          // "1-2-3"
"1-2-3".split("-");                           // ["1","2","3"]

[...new Set([1, 1, 2, 2, 3])];                // [1,2,3] 중복 제거 (41장)

📌 요약

  • 원본을 바꾸는 메서드(push·sort·splice·reverse)와 새 배열을 만드는 메서드를 구분한다.
  • map은 같은 길이의 변환, filter는 걸러내기, reduce는 모양 바꾸기.
  • forEach는 반환값이 없고 break도 안 된다. 새 배열이 필요하면 map.
  • sort()는 기본이 문자열 비교다. 숫자는 (a,b) => a-b를 반드시 넘긴다.
  • sort()·reverse()는 원본을 바꾼다. toSorted()·toReversed()를 쓰거나 복사 후 정렬한다.
  • 한글 정렬은 localeCompare(a, "ko").
  • 체이닝은 매번 새 배열을 만들지만 대개 가독성이 더 중요하다.
