Date의 함정

Date는 JavaScript 초기에 급하게 만들어져 설계가 나쁘기로 유명합니다. 알고 쓰면 문제없지만, 모르고 쓰면 반드시 사고가 납니다.

🌏 시간대 — 하루가 어긋나는 버그

Date는 내부적으로 UTC 기준 밀리초 숫자 하나를 저장합니다. 화면에 보여줄 때만 사용자 컴퓨터의 시간대로 변환합니다.

// 서버가 "2026-01-15" (날짜만)를 보냈다고 합시다
const d = new Date("2026-01-15");
// → 2026-01-15T00:00:00Z (UTC 자정)으로 해석됩니다

// 한국(UTC+9)에서는 1월 15일 오전 9시 → 날짜는 15일 ✅
// 미국 서부(UTC-8)에서는 1월 14일 오후 4시 → 날짜가 14일! ❌
d.getDate();   // 사용자 위치에 따라 15 또는 14

예방책

  • 서버와는 UTC 기준 ISO 문자열(2026-01-15T00:00:00Z)로 주고받습니다.
  • 날짜만 중요한 값(생일, 마감일)은 Date가 아니라 문자열 "2026-01-15" 그대로 다루는 편이 안전합니다.
  • 시간대가 중요한 서비스라면 사용자의 시간대를 명시적으로 저장합니다.

Intl — 지역에 맞게 표시하기

날짜와 숫자를 직접 문자열로 조립하지 마세요. Intl은 브라우저에 내장되어 있고, 전 세계 형식을 이미 알고 있습니다.

🌐 Intl을 써야 하는 이유

  • 이미 브라우저에 들어 있습니다. 라이브러리 용량 0.
  • 나라마다 다른 날짜 순서·구분자·통화 기호 위치를 알아서 처리합니다.
  • 천 단위 구분자를 직접 정규식으로 만들 이유가 없습니다.
  • 한국어 정렬도 Intl.Collator가 정확합니다.

성능 팁: Intl.NumberFormat 객체를 만드는 비용이 작지 않습니다. 반복문 안에서 매번 만들지 말고 한 번 만들어 재사용하세요.

날짜 라이브러리

도구특징
date-fns함수 단위로 필요한 것만 가져다 씁니다. 트리 셰이킹이 잘 됩니다
Day.js매우 가볍고 API가 익히기 쉽습니다

🛠️ 현장 노트 — 라이브러리를 넣기 전에

단순히 표시만 한다면 Intl로 충분합니다. 라이브러리가 필요한 경우는 이렇습니다.

  • 날짜 더하기·빼기가 많다 (한 달 뒤, 영업일 기준 5일 후)
  • 복잡한 시간대 변환이 필요하다
  • 사용자 입력 문자열을 정확한 형식으로 파싱해야 한다

참고로 Date의 문제를 근본적으로 해결하는 Temporal이라는 새 표준 API가 만들어지고 있습니다. 불변이고, 시간대와 달력을 명시적으로 다루며, 월이 1부터 시작합니다. 표준화가 상당히 진행되어 일부 브라우저에서 지원이 시작되었지만, 실무 도입은 지원 현황을 확인한 뒤 판단하세요.

실무 패턴

서버와 주고받기 
// ✅ 보낼 때: 항상 UTC 기준 ISO 문자열
fetch("/api/events", {
  method: "POST",
  body: JSON.stringify({ startAt: new Date().toISOString() })
});

// ✅ 받을 때: 문자열 → Date → Intl로 표시
const event = await response.json();
const startAt = new Date(event.startAt);
const label = new Intl.DateTimeFormat("ko-KR", {
  dateStyle: "medium", timeStyle: "short"
}).format(startAt);
HTML 마크업에서 (10장 복습) 
<!-- 기계용 값과 사람용 표시를 분리합니다 -->
<time datetime="2026-01-15T14:30:00Z">2026년 1월 15일 오후 11시 30분</time>

📌 요약

  • getMonth()는 0부터, getDate()는 1부터. 일관성이 없다.
  • "2026-01-15"는 UTC로, "2026/01/15"는 현지 시간으로 해석된다.
  • 잘못된 날짜는 오류가 아니라 Invalid Date다. Number.isNaN(d.getTime())으로 확인한다.
  • Date는 변경 가능하다. 복사는 new Date(d.getTime()).
  • 시간대 때문에 하루가 어긋난다. 서버와는 UTC ISO 문자열로, 날짜만 필요하면 문자열 그대로.
  • 표시는 Intl에 맡긴다. 용량 0, 전 세계 형식 지원.
  • 포맷터 객체는 한 번 만들어 재사용한다.
  • Moment.js는 새 프로젝트에 쓰지 않는다. Temporal 표준이 준비되고 있다.
