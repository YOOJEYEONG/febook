Date의 함정

Date는 JavaScript 초기에 급하게 만들어져 설계가 나쁘기로 유명합니다. 알고 쓰면 문제없지만, 모르고 쓰면 반드시 사고가 납니다.

🌏 시간대 — 하루가 어긋나는 버그

Date는 내부적으로 UTC 기준 밀리초 숫자 하나를 저장합니다. 화면에 보여줄 때만 사용자 컴퓨터의 시간대로 변환합니다.

// 서버가 "2026-01-15" (날짜만)를 보냈다고 합시다
const d = new Date("2026-01-15");
// → 2026-01-15T00:00:00Z (UTC 자정)으로 해석됩니다

// 한국(UTC+9)에서는 1월 15일 오전 9시 → 날짜는 15일 ✅
// 미국 서부(UTC-8)에서는 1월 14일 오후 4시 → 날짜가 14일! ❌
d.getDate();   // 사용자 위치에 따라 15 또는 14

예방책

  • 서버와는 UTC 기준 ISO 문자열(2026-01-15T00:00:00Z)로 주고받습니다.
  • 날짜만 중요한 값(생일, 마감일)은 Date가 아니라 문자열 "2026-01-15" 그대로 다루는 편이 안전합니다.
  • 시간대가 중요한 서비스라면 사용자의 시간대를 명시적으로 저장합니다.

Intl — 지역에 맞게 표시하기

날짜와 숫자를 직접 문자열로 조립하지 마세요. Intl은 브라우저에 내장되어 있고, 전 세계 형식을 이미 알고 있습니다.

🌐 Intl을 써야 하는 이유

  • 이미 브라우저에 들어 있습니다. 라이브러리 용량 0.
  • 나라마다 다른 날짜 순서·구분자·통화 기호 위치를 알아서 처리합니다.
  • 천 단위 구분자를 직접 정규식으로 만들 이유가 없습니다.
  • 한국어 정렬도 Intl.Collator가 정확합니다.

성능 팁: Intl.NumberFormat 객체를 만드는 비용이 작지 않습니다. 반복문 안에서 매번 만들지 말고 한 번 만들어 재사용하세요.

날짜 라이브러리

도구특징
date-fns함수 단위로 필요한 것만 가져다 씁니다. 트리 셰이킹이 잘 됩니다
Day.js매우 가볍고 API가 익히기 쉽습니다
Luxon시간대 처리가 강력합니다
Moment.js더 이상 새 프로젝트에 쓰지 않습니다. 공식적으로 유지보수 모드이며 용량이 큽니다

🛠️ 현장 노트 — 라이브러리를 넣기 전에

단순히 표시만 한다면 Intl로 충분합니다. 라이브러리가 필요한 경우는 이렇습니다.

  • 날짜 더하기·빼기가 많다 (한 달 뒤, 영업일 기준 5일 후)
  • 복잡한 시간대 변환이 필요하다
  • 사용자 입력 문자열을 정확한 형식으로 파싱해야 한다

참고로 Date의 문제를 근본적으로 해결하는 Temporal이라는 새 표준 API가 만들어지고 있습니다. 불변이고, 시간대와 달력을 명시적으로 다루며, 월이 1부터 시작합니다. 표준화가 상당히 진행되어 일부 브라우저에서 지원이 시작되었지만, 실무 도입은 지원 현황을 확인한 뒤 판단하세요.

실무 패턴

서버와 주고받기 
// ✅ 보낼 때: 항상 UTC 기준 ISO 문자열
fetch("/api/events", {
  method: "POST",
  body: JSON.stringify({ startAt: new Date().toISOString() })
});

// ✅ 받을 때: 문자열 → Date → Intl로 표시
const event = await response.json();
const startAt = new Date(event.startAt);
const label = new Intl.DateTimeFormat("ko-KR", {
  dateStyle: "medium", timeStyle: "short"
}).format(startAt);
HTML 마크업에서 (10장 복습) 
<!-- 기계용 값과 사람용 표시를 분리합니다 -->
<time datetime="2026-01-15T14:30:00Z">2026년 1월 15일 오후 11시 30분</time>

직접 해 보기

4·5부(JavaScript)를 마쳤습니다. 라이브러리 없이 순수 JavaScript로 할 일 목록을 만들어 봅니다. DOM 조작, 이벤트, 저장소, 배열·객체, 날짜 표시가 한 화면에 모두 들어가서, 지금까지 배운 것을 점검하기에 좋습니다. React를 배운 뒤 같은 앱을 다시 만들어 비교해 보면 React가 무엇을 대신해 주는지 분명히 보입니다.

🎯 과제 — 순수 JavaScript 할 일 목록

  • ☐ 입력 칸에 할 일을 쓰고 Enter나 "추가" 버튼으로 목록에 넣는다(빈 칸·공백만은 무시)
  • ☐ 체크박스로 완료 표시를 하면 글자에 취소선이 생긴다
  • ☐ 항목마다 "삭제" 버튼이 있다
  • ☐ "전체 N개 · 남은 일 M개" 요약이 항상 맞게 표시된다
  • ☐ 새로고침해도 목록이 남아 있다(localStorage). 저장이 막힌 환경에서도 오류로 멈추지 않는다
  • ☐ 각 항목에 추가한 시각을 "2026. 11. 11. 오후 3:20"처럼 한국어 형식으로 보여 준다
  • ☐ 사용자가 입력한 글자는 innerHTML이 아니라 textContent로 넣는다
  • ☐ 클릭 처리는 항목마다 리스너를 붙이지 않고 목록(ul) 하나에서 처리한다

💡 힌트

  • 설계 요령: 할 일을 객체 배열({ id, title, done, createdAt })로 들고 있고, 배열이 바뀔 때마다 render() 함수 하나로 화면을 다시 그리면 꼬이지 않습니다. 배열 메서드는 29장, 객체 복사는 28장.
  • 폼 제출 시 새로고침을 막는 preventDefault(), 요소 만들기, 이벤트 위임과 closest()는 38장을 보세요.
  • 저장소에는 문자열만 들어갑니다. JSON.stringify·JSON.parse와 try/catch는 39장.
  • 날짜는 ISO 문자열로 저장하고, 표시할 때 Intl.DateTimeFormat을 씁니다. 이 챕터 앞부분을 다시 보세요.
  • 더 해 보고 싶다면: "전체 / 남은 일 / 완료" 필터 버튼, 완료 항목 한꺼번에 지우기를 추가해 보세요.
예시 답안

요구사항을 모두 채운 한 가지 방법입니다. 체크박스를 누를 때마다 목록을 다시 그리므로 포커스가 사라지는데, 이것을 개선해 보는 것도 좋은 연습입니다.

<form id="add-form">
  <label for="new-todo">할 일</label>
  <input id="new-todo" name="title" required maxlength="100">
  <button type="submit">추가</button>
</form>
<p id="summary" aria-live="polite"></p>
<ul id="list"></ul>

<script>
  const STORAGE_KEY = "todos";
  const form = document.getElementById("add-form");
  const input = document.getElementById("new-todo");
  const list = document.getElementById("list");
  const summary = document.getElementById("summary");
  const dateFormat = new Intl.DateTimeFormat("ko-KR", { dateStyle: "medium", timeStyle: "short" });

  // 1. 저장소 읽기·쓰기는 언제든 실패할 수 있으니 감싼다 (39장)
  function load() {
    try {
      const saved = JSON.parse(localStorage.getItem(STORAGE_KEY));
      return Array.isArray(saved) ? saved : [];
    } catch {
      return [];
    }
  }
  function save() {
    try {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
    } catch {
      // 저장이 안 되는 환경이면 화면에서만 동작한다
    }
  }

  let todos = load();

  // 2. 데이터(todos)가 바뀌면 화면을 통째로 다시 그린다
  function render() {
    list.replaceChildren();
    for (const todo of todos) {
      const li = document.createElement("li");
      li.dataset.id = todo.id;

      const label = document.createElement("label");
      const check = document.createElement("input");
      check.type = "checkbox";
      check.checked = todo.done;
      const title = document.createElement("span");
      title.textContent = todo.title;          // innerHTML 금지 (38장)
      if (todo.done) title.style.textDecoration = "line-through";
      label.append(check, " ", title);

      const time = document.createElement("small");
      time.textContent = " · " + dateFormat.format(new Date(todo.createdAt));

      const del = document.createElement("button");
      del.type = "button";
      del.className = "delete";
      del.textContent = "삭제";
      del.setAttribute("aria-label", todo.title + " 삭제");

      li.append(label, time, " ", del);
      list.append(li);
    }
    const left = todos.filter(t => !t.done).length;
    summary.textContent = `전체 ${todos.length}개 · 남은 일 ${left}개`;
  }

  // 3. 추가
  form.addEventListener("submit", (event) => {
    event.preventDefault();
    const title = input.value.trim();
    if (!title) return;
    todos.push({ id: Date.now(), title, done: false, createdAt: new Date().toISOString() });
    input.value = "";
    save();
    render();
  });

  // 4. 완료·삭제는 부모 하나에서 이벤트 위임으로 처리한다 (38장)
  list.addEventListener("click", (event) => {
    const li = event.target.closest("li");
    if (!li) return;
    const id = Number(li.dataset.id);
    if (event.target.matches(".delete")) {
      todos = todos.filter(t => t.id !== id);
    } else if (event.target.matches("input[type=checkbox]")) {
      todos = todos.map(t => (t.id === id ? { ...t, done: !t.done } : t));
    } else {
      return;
    }
    save();
    render();
  });

  render();
</script>

📌 요약

  • getMonth()는 0부터, getDate()는 1부터. 일관성이 없다.
  • "2026-01-15"는 UTC로, "2026/01/15"는 현지 시간으로 해석된다.
  • 잘못된 날짜는 오류가 아니라 Invalid Date다. Number.isNaN(d.getTime())으로 확인한다.
  • Date는 변경 가능하다. 복사는 new Date(d.getTime()).
  • 시간대 때문에 하루가 어긋난다. 서버와는 UTC ISO 문자열로, 날짜만 필요하면 문자열 그대로.
  • 표시는 Intl에 맡긴다. 용량 0, 전 세계 형식 지원.
  • 포맷터 객체는 한 번 만들어 재사용한다.
  • Moment.js는 새 프로젝트에 쓰지 않는다. Temporal 표준이 준비되고 있다.
