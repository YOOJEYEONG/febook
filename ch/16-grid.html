Grid의 기본

Flexbox가 한 방향이라면, Grid는 행과 열 두 방향을 동시에 다룹니다. 표를 그리듯 격자를 먼저 정의하고 그 안에 요소를 배치합니다.

가장 기본 
.container {
  display: grid;
  grid-template-columns: 200px 1fr 100px;  /* 3개 열 */
  grid-template-rows: 60px auto 40px;      /* 3개 행 */
  gap: 16px;
}

fr — Grid만의 단위

fr은 fraction(분수)의 약자로, 남은 공간을 나누는 비율입니다.

grid-template-columns: 1fr 1fr 1fr;   /* 셋으로 균등 분할 */
grid-template-columns: 2fr 1fr;       /* 2:1 비율 */
grid-template-columns: 200px 1fr;     /* 200px 고정 + 나머지 전부 */

🧮 1fr과 33.33%가 다른 이유

%는 gap을 고려하지 않습니다. 33.33% 세 개에 gap: 16px을 주면 합이 100%를 넘어 넘칩니다. fr은 gap을 뺀 나머지를 나누므로 정확히 맞습니다. Grid·Flex 안에서는 %보다 fr이나 flex를 쓰세요.

repeat와 minmax

grid-template-columns: repeat(4, 1fr);        /* 1fr 1fr 1fr 1fr 과 동일 */
grid-template-columns: repeat(3, 100px 1fr);  /* 패턴 반복도 가능 */

grid-template-columns: repeat(3, minmax(150px, 1fr));
/* 각 칸: 최소 150px, 남으면 균등하게 늘어남 */

미디어 쿼리 없는 반응형 격자

✨ 외워 둘 가치가 있는 한 줄

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}

뜻: "칸 하나의 최소 너비는 240px. 들어갈 수 있는 만큼 열을 만들고, 남는 공간은 나눠 가져라."
화면이 넓으면 4열, 좁으면 2열, 더 좁으면 1열이 미디어 쿼리 하나 없이 자동으로 됩니다.

auto-fit과 auto-fill의 차이

둘은 아이템이 열 개수보다 적을 때만 차이가 납니다.

동작
auto-fill공간이 되는 만큼 빈 열도 만들어 둡니다. 아이템은 왼쪽부터 채워지고 오른쪽에 빈 자리가 남습니다
auto-fit빈 열을 0으로 접습니다. 그 결과 남은 아이템들이 공간을 전부 차지하도록 늘어납니다

아이템 배치하기

Grid는 눈에 보이지 않는 선(line)에 번호를 매깁니다. 열이 3개면 세로선은 4개(1~4)입니다.

선 번호로 배치 
.item {
  grid-column: 1 / 3;   /* 1번 선에서 3번 선까지 = 두 칸 차지 */
  grid-row: 2 / 4;
}

/* span 으로 개수 지정 (더 자주 씁니다) */
.item { grid-column: span 2; }   /* 어디서 시작하든 두 칸 */

/* -1 은 마지막 선 */
.full { grid-column: 1 / -1; }   /* 전체 너비 차지 */

grid-template-areas — 레이아웃을 그림으로

Grid에서 가장 직관적인 기능입니다. 글자로 배치도를 그립니다.

이름으로 배치 
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 16px;
  min-height: 100dvh;
}

.layout > header  { grid-area: header; }
.layout > nav     { grid-area: sidebar; }
.layout > main    { grid-area: main; }
.layout > footer  { grid-area: footer; }

화면 폭이 좁아지면 배치도만 다시 그리면 됩니다.

@media (max-width: 700px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  }
}

⚠️ areas 문법 규칙

  • 모든 줄의 칸 개수가 같아야 합니다. 하나라도 다르면 전체가 무효가 됩니다.
  • 같은 이름이 이어지면 병합됩니다. 단 직사각형이어야 합니다. L자 모양은 불가능합니다.
  • 빈 칸은 마침표 .로 표시합니다.

🎯 가장 짧은 중앙 정렬

.center {
  display: grid;
  place-items: center;   /* 이 한 줄로 가로·세로 완벽 중앙 */
  min-height: 100dvh;
}

암시적 격자

정의한 칸보다 아이템이 많으면, Grid는 알아서 행을 추가합니다. 그 자동 생성 행의 크기는 grid-auto-rows로 정합니다.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(120px, auto);  /* 자동 생성 행은 최소 120px */
  grid-auto-flow: row;                  /* 기본값. dense 로 하면 빈틈을 메운다 */
}

grid-auto-flow: dense는 빈 구멍에 뒤 아이템을 끌어와 채웁니다. 빽빽해 보이지만 시각적 순서와 DOM 순서가 달라져 접근성 문제가 생기므로 신중히 쓰세요.

subgrid

중첩된 Grid가 부모의 격자선을 그대로 물려받게 하는 기능입니다. 카드 여러 개의 제목·본문·버튼 높이를 서로 맞출 때 유용합니다.

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;   /* 부모의 행 선을 그대로 사용 */
}

Firefox 71+, Safari 16+, Chrome 117+에서 지원됩니다. 최신 브라우저에서는 쓸 수 있지만 지원 범위 확인 후 사용하세요.

🛠️ 현장 노트 — Grid 디버깅

크롬·파이어폭스 개발자 도구에서 display: grid인 요소 옆에 grid 배지가 뜹니다. 그것을 누르면 격자선과 선 번호가 화면에 겹쳐 표시됩니다. Grid는 눈에 안 보이는 선을 다루기 때문에 이 도구 없이 디버깅하면 시간이 몇 배로 듭니다. Grid를 쓸 때는 반드시 이 오버레이를 켜 두세요.

📌 요약

  • Grid는 행과 열 두 방향을 동시에 다룬다. Flex는 한 방향.
  • fr은 gap을 뺀 나머지를 나눈다. %보다 안전하다.
  • repeat(auto-fit, minmax(240px, 1fr)) — 미디어 쿼리 없는 반응형 격자.
  • auto-fit은 빈 열을 접고, auto-fill은 빈 열을 남긴다.
  • grid-template-areas로 레이아웃을 글자 그림으로 그린다. 칸 수가 맞아야 하고 직사각형만 가능.
  • place-items: center 한 줄이면 완벽한 중앙 정렬.
  • 개발자 도구의 grid 오버레이를 반드시 켜고 작업한다.
