주축과 교차축

Flexbox는 한 방향으로 줄 세우는 도구입니다. 그 방향을 주축(main axis)이라 하고, 그것과 직각인 방향을 교차축(cross axis)이라 합니다.

방향에 따른 축 
flex-direction: row (기본값)        flex-direction: column
┌──────────────────────────┐        ┌──────────┐
│ [1] [2] [3]  → 주축      │        │   [1]    │ ↓
│                          │        │   [2]    │ 주축
│ ↓ 교차축                 │        │   [3]    │
└──────────────────────────┘        └──────────┘
                                      → 교차축

🔑 이것만 기억하면 절반은 끝납니다

  • justify-content → 주축 방향 정렬
  • align-items → 교차축 방향 정렬

즉 flex-direction: column으로 바꾸면 두 속성의 역할이 서로 바뀝니다. "세로 정렬이 왜 안 되지?"의 원인은 대부분 이것입니다.

컨테이너에 주는 속성

속성값설명
displayflex / inline-flexflex 컨테이너로 만든다. 직계 자식들만 flex 아이템이 된다
flex-directionrow(기본) · column · row-reverse · column-reverse주축 방향
flex-wrapnowrap(기본) · wrap기본값은 줄바꿈 안 함. 넘치면 아이템을 찌그러뜨린다
justify-contentflex-start · center · flex-end · space-between · space-around · space-evenly주축 정렬
align-itemsstretch(기본) · flex-start · center · flex-end · baseline교차축 정렬
align-content위와 유사여러 줄일 때(wrap 상태) 줄 전체의 교차축 정렬
gap16px, 1rem 2rem아이템 사이 간격. margin보다 훨씬 편합니다

↔️ space-between · around · evenly의 차이

space-between:  [1]        [2]        [3]     양끝은 딱 붙는다
space-around:    [1]      [2]      [3]        아이템 양옆에 같은 여백 (끝은 절반)
space-evenly:   [1]     [2]     [3]           모든 간격이 완전히 동일

아이템에 주는 속성

속성기본값설명
flex-grow0남는 공간을 얼마나 나눠 가질지. 0이면 안 늘어남
flex-shrink1공간이 모자랄 때 얼마나 줄어들지. 0이면 안 줄어듦
flex-basisauto늘리거나 줄이기 전의 기준 크기
align-selfauto이 아이템만 교차축 정렬을 따로 지정
order0시각적 순서 변경. DOM 순서는 그대로라 키보드·스크린 리더 순서와 어긋납니다. 남용 금지

flex 축약형 — 반드시 외울 세 가지

/* flex: grow shrink basis 순서 */

flex: 1;        /* = flex: 1 1 0%;    남는 공간을 균등하게 나눠 가진다 */
flex: auto;     /* = flex: 1 1 auto;  내용 크기를 존중하며 남는 공간을 나눈다 */
flex: none;     /* = flex: 0 0 auto;  절대 늘지도 줄지도 않는다 */
flex: initial;  /* = flex: 0 1 auto;  기본값. 늘지 않고 줄기만 한다 */

⚖️ flex: 1과 flex: auto의 결정적 차이

flex: 1은 basis가 0이라 내용 길이를 무시하고 공간을 똑같이 나눕니다. 글자가 3자든 300자든 정확히 같은 너비가 됩니다.
flex: auto는 basis가 auto라 내용 크기를 먼저 확보한 뒤 남는 공간을 나눕니다. 글자가 긴 쪽이 더 넓어집니다.
"칸을 똑같이 나누고 싶다"면 flex: 1입니다.

직접 만져 보기

아래는 값을 바꿔 가며 결과를 즉시 확인할 수 있는 실습판입니다. 모든 조합을 한 번씩 눌러 보세요. 글로 읽는 것보다 훨씬 빨리 이해됩니다.

외워 두면 좋은 패턴

① 완벽한 중앙 정렬 — 이제 가장 쉬운 일이 되었습니다 
.center {
  display: flex;
  justify-content: center;  /* 가로 */
  align-items: center;      /* 세로 */
  min-height: 100dvh;
}
② 헤더 — 로고는 왼쪽, 메뉴는 오른쪽 
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* 또는 밀어내기 기법: 특정 요소부터 오른쪽으로 몰기 */
.header .menu { margin-left: auto; }
③ 사이드바 고정 + 본문 가변 
.layout { display: flex; gap: 24px; }
.sidebar { flex: none; width: 240px; }  /* 절대 줄지 않음 */
.content { flex: 1; min-width: 0; }     /* 남은 공간 전부 */
④ 카드 목록 — 줄바꿈되며 균등하게 
.cards { display: flex; flex-wrap: wrap; gap: 16px; }
.card  { flex: 1 1 260px; }   /* 최소 260px, 남으면 늘어나고, 모자라면 줄바꿈 */
⑤ 푸터를 항상 화면 아래에 (내용이 짧아도) 
body { display: flex; flex-direction: column; min-height: 100dvh; }
main { flex: 1; }   /* 남는 세로 공간을 본문이 전부 차지 */

유명한 함정: 아이템이 줄어들지 않는 문제

💥 "긴 텍스트가 컨테이너를 뚫고 나가요"

flex 아이템은 min-width의 기본값이 auto입니다. 이는 "내용보다 작아지지 않는다"는 뜻입니다. 그래서 아주 긴 문장이나 줄바꿈 없는 URL이 들어가면 flex-shrink: 1이 있어도 줄지 않고 컨테이너를 밀어냅니다. 가로 스크롤이 생기는 대표적인 원인입니다.

해결 
.item {
  flex: 1;
  min-width: 0;      /* ← 이 한 줄이 해결합니다 */
}

/* 세로 방향(column)일 때는 min-height: 0 */
/* 긴 단어 자체를 끊고 싶다면 함께 */
.item { overflow-wrap: anywhere; }

🛠️ 현장 노트 — Flexbox와 Grid, 언제 무엇을

  • 한 방향으로 늘어놓는다 → Flexbox. 내비게이션 바, 버튼 묶음, 아이콘+텍스트.
  • 행과 열 두 방향을 동시에 통제한다 → Grid(16장). 페이지 전체 레이아웃, 카드 격자.
  • 둘은 경쟁 관계가 아니라 같이 씁니다. Grid로 큰 틀을 잡고 각 칸 안을 Flex로 정렬하는 조합이 가장 흔합니다.
  • 실무 감각으로는 "내용이 크기를 결정하면 Flex, 레이아웃이 크기를 결정하면 Grid" 정도가 좋은 기준입니다.

📌 요약

  • justify-content는 주축, align-items는 교차축. flex-direction을 바꾸면 역할도 바뀐다.
  • flex-wrap 기본값은 nowrap이라 넘치면 찌그러진다.
  • gap이 margin보다 편하고 안전하다.
  • flex: 1 = 1 1 0%(칸을 똑같이), flex: auto = 1 1 auto(내용 크기 존중), flex: none = 고정.
  • flex 아이템은 min-width: auto가 기본이라 안 줄어든다. min-width: 0으로 푼다.
  • order는 시각 순서만 바꾼다. 키보드·스크린 리더 순서와 어긋나므로 신중히.
  • 한 방향은 Flex, 두 방향은 Grid. 대개 함께 쓴다.
